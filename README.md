# Кинополка — учебный онлайн-кинотеатр

Учебный мини-проект React + Vite (JavaScript + JSX).  
Демонстрирует useState, props, callback, spread, filter, sort, map, key, localStorage.

## 1. Запуск

1. Установите Node.js 22.12+.
2. Откройте папку проекта в VS Code.
3. Терминал → Новая → `npm install`.
4. `npm run dev` — запуск сервера.
5. Откройте http://127.0.0.1:5173.
6. Остановка — Ctrl+C.

## 2. Что работает

- Первый экран: регистрация + вкладка входа.
- Регистрация: имя, email, пароль, повтор пароля.
- Уникальность email без учёта регистра.
- После регистрации — переход на вход; после входа — каталог.
- 10 стартовых фильмов.
- Поиск по названию и режиссёру, без учёта регистра.
- Фильтр по жанру, сортировки: режиссёр, название, год, цена.
- Вкладка «Добавить фильм» с проверкой полей.
- Постер: ссылка HTTP(S), локальный JPG/PNG/WebP до 500 КБ или заглушка.
- Сохранение аккаунтов и фильмов после перезагрузки (localStorage).
- Адаптивная вёрстка.
